# Фирменные ресурсы

Сюда кладутся официальные файлы Hard Rock Cafe.

- `logo.svg` (или `logo.png` / `logo.webp`) — подхватывается компонентом `<Logo>` автоматически

Логотип Hard Rock — товарный знак, поэтому в репозитории его нет и он не воспроизводится
рисованием. Пока файла нет, `<Logo>` показывает текстовую заглушку «HRC STARS».
