# Шрифты для PDF

Используются при генерации сертификатов (`src/server/pdf/certificate.ts`).

| Файл | Шрифт | Где на сертификате |
|---|---|---|
| `Inter-Regular.ttf` | Inter 400 | подписи, пояснения |
| `Inter-SemiBold.ttf` | Inter 600 | название программы, дата, номер, имя выдавшего |
| `Oswald-Bold.ttf` | Oswald 700 | заголовок, название кафе, имя получателя |

Те же гарнитуры, что в интерфейсе (`next/font/google` в `src/app/layout.tsx`).
Лицензия — SIL Open Font License 1.1, тексты лицензий лежат рядом: `OFL-Inter.txt`, `OFL-Oswald.txt`.
Источник — полные TTF из Google Fonts, взятые из npm-пакетов `@expo-google-fonts/inter`
и `@expo-google-fonts/oswald` 0.4.2.

Почему файлы лежат в репозитории, а не подтягиваются при сборке:

- стандартные 14 шрифтов PDF не содержат польских букв `ą ć ę ł ń ó ś ź ż`;
- `next/font` отдаёт только woff2, разрезанные по диапазонам символов, — для PDF они не годятся;
- сертификат должен собираться и на сервере без доступа в интернет.

Inter встраивается в PDF целиком, без подмножества: подмножество, которое собирает
fontkit, у Inter теряет глифы. Oswald в подмножестве отрисовывается правильно.
